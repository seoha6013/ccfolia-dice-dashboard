# 주사위 아카이브 · 코코포리아 로그 통계

코코포리아(CCFOLIA)에서 내보낸 세션 로그(`.html`)를 올리면 CoC 7판 주사위 통계와 명장면을 보여주는 정적 웹 대시보드예요.
**업로드한 파일은 브라우저 메모리 안에서만 처리되고, 어떤 서버로도 전송되지 않아요.**

## 기능
- 드래그 앤 드롭 / 여러 파일 한 번에 / 샘플 로그 체험
- 요약: 총 판정 수, 평균 주사위, 최고 행운 캐릭터(평균이 가장 낮은 캐릭터, 3회 이상 굴린 경우), 최다 판정 기능
- 캐릭터·탭 필터, 캐릭터별 비교 표
- 성공 등급 분포(도넛), 기능 Top 5 성공률(막대), 주사위 흐름(꺾은선)
- 🎲 명예의 전당: 대성공·대실패 또는 1~5 / 96~100이 나온 판정을 앞뒤 대사 2줄과 함께 카드로 표시하고, 이미지로 저장하거나 텍스트로 복사
- 라이트/다크 모드, 모바일 대응

## 폴더 구조
```
index.html        화면
css/style.css     디자인 (파스텔, 라이트/다크)
js/parser.js      코코포리아 로그 파서 (정규표현식)
js/app.js         통계 계산 · 차트(Chart.js) · 명예의 전당(html2canvas)
sample-log.html   테스트용 샘플 로그 (가상의 세션)
```

## 파싱 방식
코코포리아 로그의 한 줄은 `<p><span>[탭]</span><span>캐릭터명</span> : <span>메시지</span></p>` 형태예요.
span이 없는 로그는 `[탭] 캐릭터명 : 메시지` 줄 패턴으로 대신 읽어요.

| 정규식 | 하는 일 |
|---|---|
| `\(\s*1D100\s*<=\s*(\d{1,3})\s*\)` | 1D100 판정인지 확인하고 목표치를 꺼냄 |
| `(\d{1,3})\s*[＞>→]\s*([^＞>→]+?)\s*$` | 맨 끝의 `＞ 26 ＞ 어려운 성공`에서 최종 눈과 결과 문구를 꺼냄 (보너스 주사위 `46, 26 ＞ 26`도 최종 값으로 읽음) |
| `^\s*S?\s*(?:CCB?\|CBRB?\|1D100)\s*(?:\(-?\d+\))?\s*<=\s*\d{1,3}\s*` | 앞의 명령어(`CC<=80`, `CC(1)<=70`, `S CCB<=50` …)를 지움 |
| `^([\s\S]*?)\s*\(\s*1D100` | 명령어와 `(1D100` 사이를 기능명으로 씀. `사격(권총)`처럼 괄호가 든 이름도 살아남음 |

결과 문구는 대성공 → 대실패 → 극단적 성공 → 어려운 성공 → 보통 성공 → 실패 순서로 검사해요(‘대실패’가 ‘실패’로 잘못 잡히지 않게). 일본어 로그(クリティカル, ハード成功 …)도 읽어요.
`1D3`, `1D6+1D4` 같은 1D100이 아닌 굴림은 통계에서 빠져요.

## 로컬에서 실행
파일을 더블클릭해서 열어도 업로드는 되지만, **샘플 불러오기**는 브라우저 보안 때문에 로컬 서버가 필요해요.
```
cd ccfolia-dice-dashboard
python -m http.server 8000
```
그다음 브라우저에서 http://localhost:8000 을 열어요. 주소 뒤에 `?sample`을 붙이면 샘플이 바로 열려요.
